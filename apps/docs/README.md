# Reserve App Docs

Next.js docs app placeholder for Reserve App.

The main API documentation is currently generated by the NestJS API and served
through Swagger UI:

```txt
http://localhost:3000/docs
```

## Local Development

Run from the repository root:

```sh
yarn workspace docs dev
```

The docs app runs on:

```txt
http://localhost:3001
```

## Checks

```sh
yarn workspace docs check-types
yarn workspace docs lint
yarn workspace docs build
```
